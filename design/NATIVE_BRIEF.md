# Live native tracker redesign

## Scope and approval

User: “apply it”, after confirming that the browser preview had not replaced the
actual tracker. Apply the approved preview's design to the default native Python
Tkinter application. Preserve parser, card database, private match journal,
localization and conservative combat model. No browser service or new dependency.

## Direction contract

THESIS: a readable floating macOS utility, with real observations rather than a
single undifferentiated text dump. Operate mode.

OWN-WORLD: inherit `preview/DESIGN.md`: system-like type, neutral layered dark and
light surfaces, restrained blue actions, explicit contrast and aligned numeric
columns. Native Tk adapts the browser styling; do not claim AppKit glass.

STORY: check round, resources and all friendly minions first; inspect the last
known opponent board, then expand secondary economy/shop/combat reasoning.
Review real journal entries and adjust local appearance without losing data.

FIRST VIEWPORT: a draggable titlebar, four-view sidebar, opponent notebook and
complete compact board panel; missing logs show a helpful waiting state instead
of sample numbers. Demo-only synthetic values stay labeled. Narrow native
windows retain access through scrolling and structural reflow.

FORM: approved code-led preview composition ported to Tk; no open visual-world
selection, seed or raster comp. Controls keep their native desktop semantics;
frameless/topmost, resizing and the existing global shortcut remain.

FINISH: unreviewed and undocumented is unfinished; this build ends with the
finish review, the verdict, DESIGN.md, and every shipping raster carrying its
provenance.
