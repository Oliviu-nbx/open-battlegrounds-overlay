# Local macOS interface preview

## Scope and mode

Operate: standalone HTML/CSS/JavaScript design preview, with a Python standard-library localhost server. The user's approval of the offered local interactive preview confirms this task. No Figma or tracker runtime modifications.

## Audience and job

A Mac player checks their current round, economy, board and last observed opponent without confusing observations with predictions. History supports retrospective review; settings preview appearance and density.

## Direction

Continue the already chosen macOS utility world: system typography, quiet dark surfaces, native-style window chrome and restrained blue interactive emphasis. Preserve platform density instead of applying the UI catalog's marketing layout. Code-led implementation of the explicitly approved interactive prototype; no new visual-world selection or generated image comps.

## First viewport

An actual working interface, not a landing page: sidebar navigation, opponent notebook, and a compact floating overlay displaying round 7, tier 4, gold 8, a five-minion board and explainable shop hints. Sample-data provenance is visible.

## Signature interaction and states

Changing the sample game phase swaps recruit/economy content for combat coverage or a recoverable waiting/access state. Opponent selection changes the last-observed board. Compact mode retains the critical summary. History selection opens match details. Settings affect both appearances and persist only in a preview-specific browser key. Respect reduced motion and preserve keyboard focus on updates.

## Boundaries and acceptance

Everything stays local and synthetic; no real permissions are requested and no fake live odds are shown. Verify desktop and narrow widths, all navigation and phase states, light/dark themes, filtering, reset, compact mode, keyboard shortcuts and reduced-motion behavior. Document the resulting tokens inside this preview directory; leave existing product files unchanged.
