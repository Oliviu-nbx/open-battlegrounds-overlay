# Security policy

## Supported versions

Security fixes are made against the latest release on `main`.

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability. Use GitHub's private vulnerability reporting for this repository when available, or contact the repository owner through GitHub with a concise reproduction and impact summary. Do not include personal Power.log data, account names, or other private game data.

This project reads local game-log files and may fetch public card metadata or artwork on demand. Reports involving file handling, log parsing, packaging, update/release integrity, or network requests are especially useful.
